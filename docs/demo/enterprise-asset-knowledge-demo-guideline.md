# 企业资料资产化与场景知识库 DEMO 纲要

> 状态：当前战略与演示制作纲要。已启动 `docs/contracts/frozen-v2-integration-contract.md` 作为当前跨任务权威契约；v1 保留为历史验收基线。本文不代表生产发布、真实公共盘安全闭环或金融业务上线许可。

## 一句话定位

本项目主线是企业资料的文件整理、资产版本化、知识库建立、索引检索与可解释业务问答；金融资料匹配只是第一套可替换场景板块。

对外沟通时不要先说成“通用平台”。面对具体客户，先说清楚一个窄场景能解决什么；内部架构继续沉淀可复用底座。

## 主线能力

主线底座保持不变：

1. 文件进入系统：用户上传资料，或从公共盘选择资料。
2. 资产化：每份资料生成 `Asset / AssetVersion`，保留来源、版本、路径、哈希、解析状态。
3. 文件整理：根据场景规则进行分类、命名、归档、元数据补齐和影响预览。
4. 知识库建立：解析 PDF/DOCX 等资料，清洗、切片、索引。
5. 权限检索：用户只能检索自己有权访问的资产版本。
6. 场景问答：根据不同业务板块切换规则库、提示词和回答模板。
7. 可解释输出：回答必须引用资料版本、规则来源和依据。
8. 审计留痕：记录资料版本、规则版本、查询、匹配、确认和执行结果。

## 场景层

场景层是可替换的，不改变底座：

| 场景 | 输入资料 | 规则/知识库 | 问答目标 |
| --- | --- | --- | --- |
| 金融资料匹配 | 客户模拟资料、收入/流水/资产/负债说明 | 银行准入规则样例 | 资料匹配度、可匹配银行、缺失材料、依据 |
| 投标资料检查 | 企业资质、业绩、证书、报价文件 | 招标文件要求 | 是否满足投标要求、缺什么、风险点 |
| 供应商准入 | 营业执照、资质、合同、履约记录 | 准入规则 | 是否可入库、风险等级、补充材料 |
| 合同审查 | 合同、补充协议、往来记录 | 条款规则与历史案例 | 风险条款、修改建议、引用依据 |
| 项目归档 | 项目文档、交付物、验收材料 | 归档清单 | 是否齐套、缺失项、交付状态 |

## 当前首个客户演示板块

当前客户沟通优先使用“金融资料匹配”板块，但不把项目写死为贷款系统。

推荐演示话术：

> 用户上传模拟资料后，系统把资料版本化、结构化，再根据银行规则库样例做资料匹配度预评估，输出可匹配的银行类型、缺失材料和引用依据。结果仅供信息参考，不参与贷款申请、审批、授信、额度测算或金融产品销售。

演示问题示例：

- “这个客户资料匹配度是多少？”
- “能匹配哪些示例银行要求？”
- “为什么推荐示例银行 A？”
- “还缺哪些材料？”
- “哪些条件导致暂不匹配？”
- “这个结论依据哪份资料和哪条规则？”

回答必须包含：

- 资料匹配度评分，不称为信用评分或授信评分。
- 可匹配、可能匹配、暂不匹配的银行规则样例。
- 缺失材料清单。
- 引用的资料 `AssetVersion`、chunk/page/paragraph 和规则版本。
- 明确免责声明。

## 技术边界

底座边界不变：

- 控制面/BFF 持有可信身份、`Asset / AssetVersion`、权限、规则版本、计划、审计。
- RAG 只读取已授权的 active `AssetVersion` 范围，不维护第二套资产或权限权威。
- Dify/LLM 可生成候选整理计划、问答草稿或解释文本，但不能生成授权结论、执行凭证、贷款结论或最终评分权威。
- FastAPI 仍是文件写入执行边界；金融资料匹配板块首轮不需要真实公共盘移动时，不强行展示文件写入能力。
- 规则匹配优先使用确定性规则；LLM 只做自然语言解释和问答润色。
- 所有演示数据必须为模拟或脱敏数据；不得使用真实身份证、真实流水、真实征信或真实银行内部规则。

## 当前制作调整

现有公共盘演示可以调整为“提供金融资料匹配服务的公司”的模拟环境：

1. 将模拟员工输入材料换成金融资料相似的模拟数据。
2. 继续建立 `Asset / AssetVersion`。
3. 继续解析、切片、索引 PDF/DOCX。
4. 把检索问题改为资质匹配、银行规则匹配、缺失材料和依据。
5. 银行规则使用明确标注的演示规则样例。
6. 保留权限、审计、版本化引用和负向控制。

技术路径不要求大改；主要变化是样例数据、规则库、提示词和回答模板。

## 对外表达原则

对外窄说，内部宽做：

- 对金融客户：先说“资料预评估与银行规则匹配 DEMO”。
- 对其他客户：换成对应场景，如投标资料检查、供应商准入、合同审查。
- 对团队内部：统一理解为“企业资料资产化 + 场景知识库 + 权限检索 + 可解释业务问答”。

不要对外直接宣称：

- 已覆盖所有行业。
- 已完成金融智能决策平台。
- 可做贷款审批、授信或额度测算。
- 真实公共盘旁路写已阻断。
- 生产级知识库、Qdrant、PostgreSQL、OS parser sandbox 已完成。
